# راهنمای فارسی — Xray Auto-Direct v1

این پروژه برای زمانی است که خروجی پیش‌فرض Xray از WARP عبور می‌کند، اما بعضی مقصدها باید با IP ثابت Direct خارج شوند.

تا زمان انتشار نسخهٔ رسمی، این repository فقط محل آماده‌سازی پروژه است و نصب‌کنندهٔ عمومی ندارد.

## منطق پروژه

ترافیک کاربر هرگز برای تشخیص مسیر استفاده نمی‌شود. اسکریپت یک Shadow Xray و یک هویت مستقل WARP دارد؛ probe فقط از همان مسیر Shadow عبور می‌کند.

اگر WARP در Shadow برای یک مقصد واقعاً ناموفق باشد و Direct از IP رزروشده موفق باشد، مقصد می‌تواند بدون restart تولید به Direct اضافه شود. خرابی Shadow باعث انتقال ترافیک کاربر به Direct نمی‌شود.

## تنظیمی که کاربر تغییر می‌دهد

فایل `policy.json` سه فهرست دارد:

- `pinned_direct_suffixes`: مقصدهای ثابت Direct؛ مانند دامنه‌های پرداخت.
- `pinned_warp_suffixes`: مقصدهایی که باید روی WARP بمانند؛ مانند OpenAI در یک نمونهٔ رایج.
- `manual_direct_suffixes`: مقصدهایی که مدیر با تصمیم خودش Direct می‌کند.

نمونهٔ ساختار در [policy.example.json](../policy.example.json) است.

## اصل ایمنی

دامنه‌های حساس مالی نباید با Auto-Direct تغییر مسیر بگیرند. آن‌ها باید صریحاً در `pinned_direct_suffixes` قرار بگیرند تا خروجی‌شان ثابت بماند.
